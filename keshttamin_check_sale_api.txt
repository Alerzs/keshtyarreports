ارسال فروش چکی از کشت‌یار به کشت‌تأمین
=====================================

بعد از تایید فروش چکی، کشت‌یار فقط این سه مقدار را POST می‌کند.
تا پاسخ موفق نیاید، اعلام فروش تایید نمی‌شود.

متد: POST
آدرس: https://keshttamin.ir/api/keshtyar/check-sales

هدرها:
  Content-Type: application/json; charset=utf-8
  Accept: application/json
  X-Api-Key: <کلید مشترک>
  User-Agent: Keshtyar/check-sale

بدنه:
  sale_amount       حجم معامله، تومان، عدد صحیح
  check_count       تعداد چک‌ها
  check_due_dates   سررسید هر چک، میلادی، YYYY-MM-DD

نمونه:
{
  "sale_amount": 2000000,
  "check_count": 1,
  "check_due_dates": ["2026-12-01"]
}

پاسخ موفق: وضعیت ۲xx و {"ok": true}
پاسخ ناموفق: هر وضعیت دیگر، یا ok غیر از true.
اگر کلید خالی یا نادرست باشد: 401
